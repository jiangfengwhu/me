# AI Agent 学习工坊

1920×1080 / 16:9 / 26 秒 / 30fps / 无口播，原创配乐与同步音效。

语言：cursor-demo + system-diagram；路线：continuous。既有作品集的产品演示方向已经确定，不另起三套风格方案。

一句话：把 Agent 从黑箱，变成可以观察和复盘的执行过程。

Palette: 蓝灰 #e2e8f0 55% · 白 #ffffff 30% · 靛蓝 #4f62e8 10% · 墨色 #1c2430 5%；逐值取自真实产品 web/src/styles.css。

素材：本机 工作/ai-agent/teaching-agent/web/src：SiteHeader、App PRESETS、Inspector 与 styles.css。复建真实标签，不调用模型，不展示虚构运行速度；操作过程明确标为教学演示。

节奏表：0–4 提问与窗口显现；4–8 规划；8–12 工具调用逐个落点；12–16 事件轨迹（burst）；16–22 上下文压缩与恢复；22–26 品牌。能量 6→5→7→9→6→3。

连续性链：同一条鉴权问题 → Plan 列表 → grep/read_file 事件 → 运行轨迹 → 上下文与 checkpoint → 回到同一会话。

关键帧设计：hook 1.2s；信息最密 10.5s；hero 20s；end 24s。用户要求不检查，因此不生成检查帧、不运行 check/qa、不导出 MP4。

声音：120 BPM，D，三音动机；marimba 主旋律、pad 和声、bass、轻鼓组。关键落点配置点击/落物/移动音，结尾回到动机。
